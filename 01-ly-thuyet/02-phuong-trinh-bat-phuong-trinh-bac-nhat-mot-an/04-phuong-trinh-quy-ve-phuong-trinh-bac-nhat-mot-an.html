Bài 4. Phương trình quy về phương trình bậc nhất một ẩn

Hai dạng: phương trình tích và phương trình chứa ẩn ở mẫu. Dạng thứ hai gần như chắc chắn có trong đề kiểm tra (câu 1a).

4.1. Phương trình tích

Sách giáo khoa

(ax + b)(cx + d) = 0 ⇔ ax + b = 0 hoặc cx + d = 0. Một tích bằng 0 khi có ít nhất một thừa số bằng 0.

Khi nào dùng

Vế phải là 0 và vế trái là tích, hoặc phân tích được thành tích (đặt nhân tử chung, hằng đẳng thức). Nếu vế phải khác 0, phải chuyển hết sang một vế trước.

Ví dụ. (x − 2)(3x + 1) = 0 ⇔ x = 2 hoặc x = −1/3.   x² = 3x ⇔ x(x − 3) = 0 ⇔ x = 0 hoặc x = 3.
Lỗi hay gặp: chia hai vế cho biểu thức chứa x làm mất nghiệm (từ x² = 3x chia cho x thì mất nghiệm x = 0).

4.2. Mẫu thức chung và nhân tử phụ

Nhắc lại (lớp 8)

Phân tích mỗi mẫu thành nhân tử. Mẫu thức chung (MTC) là tích các nhân tử khác nhau, mỗi nhân tử lấy với số mũ cao nhất. Nhân tử phụ của một mẫu = MTC chia cho mẫu đó.

Khi nào dùng

Trước khi khử mẫu ở phương trình chứa ẩn ở mẫu. Nếu một mẫu đã là tích của các mẫu còn lại thì nó chính là MTC.

Ví dụ. Các mẫu x − 2, x + 1, (x − 2)(x + 1) ⇒ MTC = (x − 2)(x + 1). Nhân tử phụ lần lượt là x + 1, x − 2, 1.
Lỗi hay gặp: lấy MTC là tích cả ba mẫu, phương trình thành bậc cao không cần thiết.

4.3. Phương trình chứa ẩn ở mẫu

Sách giáo khoa
  1. Tìm điều kiện xác định (ĐKXĐ): mọi mẫu thức khác 0.
  2. Quy đồng mẫu hai vế rồi khử mẫu (nhân hai vế với MTC).
  3. Giải phương trình nhận được.
  4. Đối chiếu ĐKXĐ, loại giá trị không thỏa; kết luận nghiệm.

Khi nào dùng

Ẩn nằm dưới mẫu số. Bốn bước là bắt buộc trong bài thi; bước 1 và bước 4 thường có điểm riêng.

Ví dụ. 1x − 1 = 2. ĐKXĐ: x ≠ 1. Khử mẫu: 1 = 2(x − 1) ⇔ x = 32 (thỏa ĐKXĐ). Vậy phương trình có nghiệm x = 3/2.
Lỗi hay gặp: quên ĐKXĐ hoặc không đối chiếu (nhiều trường trừ 0,25 điểm); khử mẫu quên nhân nhân tử phụ với cả tử; nhân chéo thiếu hạng tử khi một vế có hai phân thức.

Tự luyện

  1. (2x − 1)(x + 4) = 0.
  2. x² − 5x = 0.
  3. 3x + 2 = 1x − 2.
  4. 2x − 1 + 3x + 2 = x + 7(x − 1)(x + 2).
Đáp số
  1. x = 1/2 hoặc x = −4.
  2. x(x − 5) = 0 ⇒ x = 0 hoặc x = 5.
  3. ĐKXĐ x ≠ ±2; 3(x − 2) = x + 2 ⇔ x = 4 (thỏa).
  4. ĐKXĐ x ≠ 1, x ≠ −2; 2(x + 2) + 3(x − 1) = x + 7 ⇔ 5x + 1 = x + 7 ⇔ x = 3/2 (thỏa).
