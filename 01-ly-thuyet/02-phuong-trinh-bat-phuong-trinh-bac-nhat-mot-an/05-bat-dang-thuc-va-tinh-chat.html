Bài 5. Bất đẳng thức và tính chất

Bài nền cho bài 6. Điều quan trọng nhất: nhân hoặc chia hai vế với số âm thì phải đổi chiều.

5.1. Bất đẳng thức

Sách giáo khoa

Hệ thức dạng a < b, a > b, a ≤ b, a ≥ b gọi là bất đẳng thức; a là vế trái, b là vế phải. Hai bất đẳng thức a < b và c < d gọi là cùng chiều.

Ví dụ. "Số tiền phải trả không vượt quá 500 000 đồng" → T ≤ 500 000.
Lỗi hay gặp: lẫn < với ≤, làm mất hoặc thêm giá trị biên.

5.2. Tính chất

Sách giáo khoa
  • Bắc cầu: a < b và b < c ⇒ a < c.
  • Cộng: a < b ⇒ a + c < b + c (không đổi chiều). Hệ quả: chuyển vế đổi dấu.
  • Nhân với số dương c > 0: a < b ⇒ ac < bc (không đổi chiều).
  • Nhân với số âm c < 0: a < b ⇒ ac > bc (đổi chiều).

Khi nào dùng

Mỗi bước biến đổi bất phương trình (bài 6) đều dựa vào đây. Trước khi chia hai vế, nhìn dấu của số chia.

Ví dụ. −2x < 6, chia hai vế cho −2: x > −3 (đổi chiều).   3x ≤ 12 ⇒ x ≤ 4 (chia cho 3 dương, giữ chiều).
Lỗi hay gặp: chia cho số âm mà không đổi chiều. Lỗi mất điểm phổ biến nhất của chương.

Tự luyện

  1. Viết thành bất đẳng thức: tuổi của An (x) ít nhất là 15.
  2. Cho a < b. So sánh 2a + 1 với 2b + 1; so sánh −3a với −3b.
  3. Từ −5x ≥ 20, tìm x.
Đáp số
  1. x ≥ 15.
  2. 2a + 1 < 2b + 1; −3a > −3b.
  3. x ≤ −4 (chia cho −5, đổi chiều).
